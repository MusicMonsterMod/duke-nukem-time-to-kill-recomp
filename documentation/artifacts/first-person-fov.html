3. What does a degree value mean?

Horizontal or vertical?

Horizontal FOV measures the angle across the picture. Vertical FOV measures the angle from top to bottom. With the same vertical angle, a wider screen shows more horizontally.

For an ideal rectilinear camera with displayed aspect ratio a:

h = 2 atan(a tan(v / 2))

Angles must use consistent units during calculation. This relationship explains the choice; it does not measure TTK's current camera.

Why no default degree number yet?

The source comment describes H=256 as roughly 64 degrees wide, using a 160-unit half-width. The widescreen code also describes a 512x240 guest screen. Guest coordinates, pixel aspect and presentation scaling must be reconciled before declaring the player's displayed angle.

D14A must measure and document the convention. Options include vertical degrees, actual horizontal degrees, or horizontal degrees referenced to 4:3. No convention or slider limits are approved by this intake.

A real projection change

A wider FOV reveals more of the scene and makes a fixed object occupy less of the frame. Stretching the finished picture changes proportions without revealing the missing scene. D14A must demonstrate the former and preserve correct aspect.

The existing H override changes a projection input. Its presence alone does not prove correct culling, aim alignment or first-person presentation at every value.
