# Full 16x16 HUD item icons (kept)

The user's first versions of the medkit, steroids and power-up coin icons, drawn
to the full 16x16 edge, with their 15-colour reductions. D08A21 (2026-10-08)
replaced the active icons in `assets/ui/items/` with 14x14 art inside the 16x16
canvas, so nothing touches the HUD box frame. These are kept for a future
interface where full-size icons fit better. Nothing in the build reads them.

`hud-challenge.png` is the full 16x16 version of the D08A20 challenge item icon
(converted losslessly from the user's `challenge-16.gif`, 2026-10-09); the
active 14x14 version is `assets/ui/items/hud-challenge.png`.
